Ruleset
A collection of personally maintained rules for Mihomo / OpenClash.
This repository contains domain rules collected and organized based on my own network environment, usage habits, and personal requirements. The rules are primarily intended for my own use and are continuously updated according to actual usage.
These rules are highly environment-dependent and are not intended to be a universal ruleset. They may not be suitable for other users, networks, ISPs, regions, or proxy configurations.
Some domains may require proxy access in my environment but may work normally through a direct connection elsewhere. Likewise, domains that are directly accessible in my environment may require a proxy in other networks.
Use these rules at your own discretion. No guarantee is provided regarding compatibility, completeness, accuracy, or suitability for any particular network environment.
This repository is maintained for personal use only.
